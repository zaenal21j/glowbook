# Pemeriksaan paket belajar

Tanggal: 14 Oktober 2026. Acuan source aplikasi: `cb1cc60`.

- Panduan utama: 33 bab, sekitar 7.600 kata, dengan snippet project dan contoh latihan dibedakan.
- Workbook: 18 latihan dan pembahasan, disertakan dalam PDF serta HTML/Markdown terpisah.
- PDF: 45 halaman dan 34 entry bookmark (33 bab + lampiran), daftar isi bernomor halaman.
- Semua 45 halaman PDF dirender; contact sheet ditinjau dan halaman kode/booking/Upwork diperiksa pada ukuran lebih besar.
- Pemeriksaan posisi karakter PDF tidak menemukan teks di luar margin aman.
- Tiga HTML diperiksa: tidak ada ID duplikat atau tautan lokal/anchor yang hilang.
- Atlas mencakup 327 file / 17.031 baris source yang terlacak Git; setiap file memiliki ringkasan, kode bernomor dan petunjuk pola. Ini bukan penjelasan semantik satu per satu untuk seluruh baris.
- Referensi official Rails, Hotwire/Stimulus dan Upwork diperiksa untuk istilah serta pencatatan waktu. Snippet project tetap mengacu kode lokal, bukan implementasi tutorial eksternal.
- Secret lokal, master key, dump, upload, library pihak ketiga dan aset build tidak disertakan. Password demo/test yang muncul dalam source bukan kredensial layanan nyata.

Tidak ada perubahan source aplikasi, konfigurasi lokal, database atau kredensial. Suite aplikasi tidak dijalankan ulang untuk pembuatan dokumentasi ini. Perintah pengujian/deployment di buku adalah materi belajar dan harus dijalankan pada lingkungan yang sesuai oleh pembaca.
